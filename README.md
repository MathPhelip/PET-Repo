Repositório oficial de materiais didáticos, simulações numéricas e algoritmos de processamento desenvolvidos no âmbito do **Programa de Educação Tutorial (PET-Física)** da **Universidade Federal do Rio Grande do Norte (UFRN)**. 

O projeto **PET.py** é focado na aplicação da computação científica em Python para a formulação, resolução e visualização de problemas físicos clássicos e de fronteira (com ênfase em Geofísica Computacional e Métodos Numéricos).

## 🚀 Como Executar Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com/MathPhelip/PET.py.git
cd PET.py
```

### 2. Instalar as dependências
```bash
pip install -r requirements.txt
```

### 3. Iniciar o Jupyter Lab
```bash
jupyter lab
```
