Official repository of educational materials, numerical simulations, and processing algorithms developed within the scope of the **Tutorial Education Program (PET-Física)** at the **Federal University of Rio Grande do Norte (UFRN)**. 

The **PET.py** project focuses on the application of scientific computing in Python for the formulation, solution, and visualization of classical and frontier physical problems (with an emphasis on Computational Geophysics and Numerical Methods).
